Proyecto Integrador: Colección Cofrade

1. Descripción del proyecto

Este proyecto consiste en una página web dedicada a mi colección de artículos relacionados con la Semana Santa.

La colección comenzó en 2018 y actualmente cuenta con más de 972 artículos de diferentes lugares y años.

Mi objetivo es conseguir el récord Guinness World Records 2028 con la colección cofrade más grande del mundo.

2. Objetivos

Dar a conocer mi colección cofrade.

Mostrar los diferentes artículos que la forman.

Organizar los artículos por categorías.

Documentar el crecimiento de la colección.

Alcanzar el objetivo Guinness World Records 2028.

3. Contenido de la página web

Inicio: presentación del proyecto y de la colección.

Contacto: apartado para facilitar el contacto.

Articulo: apartado donde se descglosa los detalles de los articulos
